# 우리집 자산관리

부부 자산·수입·지출을 통합해 월별 현금흐름과 30년 시뮬레이션, 가계부, 추천을 보여주는 GitHub Pages 사이트입니다.

- **데이터는 구글 시트(`assetmanager`)에만 저장**됩니다. 이 저장소에는 코드만 있고 개인 데이터는 없습니다.
- 접속하려면 **보안코드**가 필요합니다 (Apps Script가 확인, 5회 실패 시 15분 잠금).
- 금액 단위는 만원입니다 (가계부만 원).

```
docs/            GitHub Pages 사이트 (index.html, app.js, engine.js, advisor.js, style.css, vendor/chart.umd.js)
apps-script/     구글 시트에 붙여넣는 백엔드 (Code.gs)
private/         개인 초기 데이터(Seed.gs) — .gitignore 처리, 절대 커밋하지 않음
```

## 설치 순서

1. 구글 시트 `assetmanager` 열기 → **확장 프로그램 > Apps Script**
2. `apps-script/Code.gs` 전체를 붙여넣기 (기존 코드 삭제) → 저장
3. (선택) 파일 추가(+) → 스크립트 → 이름 `Seed` → `private/Seed.gs` 내용 붙여넣기 → 저장
4. 시트를 새로고침하면 **[자산관리]** 메뉴가 생깁니다.
   - ① 시트 초기화(탭 생성)
   - ② 보안코드 설정 (8자 이상, 영문+숫자 권장)
   - ③ 초기 데이터 입력 (Seed.gs를 붙여넣은 경우)
   - 처음 실행하면 구글 권한 승인 창이 뜹니다 (본인 계정, "고급 > 이동" 선택)
5. **배포 > 새 배포 > 웹 앱** — 실행 사용자: **나**, 액세스 권한: **모든 사용자** → 웹 앱 URL 복사
6. 저장소 **Settings > Pages** — Branch: `main`(또는 사용 중인 브랜치), Folder: `/docs`
7. 사이트에 접속해 웹 앱 URL(처음 한 번)과 보안코드 입력
8. 가족 폰 연결: 로그인 후 **관리 > 연결·보안 > 와이프 폰에 연결하기**의 링크를 복사해 와이프에게 개인 채팅으로 보냅니다. 그 링크를 한 번 열면 연결 주소가 폰에 저장되고, 이후에는 보안코드만 입력하면 됩니다. (링크에는 연결 주소가 들어 있으니 공개 채널에 올리지 마세요. 보안코드는 따로 알려주세요.)

## 시세 자동 갱신 (GOOGLEFINANCE)

1. 사이트 **관리 > 투자 종목**에서 종목마다 **시세 코드**를 입력합니다 (예: 기아 `KRX:000270`). [시세 코드 자동 채우기] 버튼으로 일부를 채울 수 있습니다.
2. 시트 메뉴 **[자산관리] > ④ 시세 자동 갱신 켜기** — 1시간마다 시세를 읽어 현재가에 저장합니다. 처음 실행하면 추가 권한(트리거) 승인 창이 뜹니다.
3. **배포 관리 > 새 버전**으로 다시 배포합니다 (새 기능이 웹 앱에 반영되도록).
4. 실패 알림을 받으려면 Apps Script 왼쪽 **트리거 > autoRefresh > 실패 알림 설정**에서 "즉시 알림"을 고릅니다 (3회 연속 실패하면 실행 실패로 기록됩니다).
5. 문제가 생기면 시트의 `Log` 탭(최근 실행 기록)과 `Quotes` 탭(시세 원본)을 확인하세요.

안정성 장치: 동시 실행 잠금 · 재시도 4회 · 기존 시세와 35% 넘게 다른 값은 반영하지 않고 이전 값 유지 · 조회 실패 종목은 이전 값 유지 · 사이트에 마지막 성공 시각과 최근 문제 표시.

코드를 고친 뒤에는 Apps Script에서 **배포 관리 > 새 버전**으로 다시 배포해야 반영됩니다.

## 보안 메모

- "모든 사용자" 접근은 GitHub Pages에서 호출하기 위해 필요합니다. 대신 **보안코드가 유일한 문**이므로 길게(12자 이상) 정하세요.
- 보안코드는 해시로만 저장되고, 로그인 토큰은 6시간 후 만료됩니다.
- 웹 앱 URL과 보안코드는 가족 외에 공유하지 마세요. URL은 브라우저(localStorage)에만 저장되고 코드에는 없습니다.
- 사이트 코드에는 개인 정보가 없지만, 저장소가 public이면 코드(계산 로직)는 누구나 볼 수 있습니다.
